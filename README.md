# 刘永昌老师 · AI 角色蒸馏

将广州大学附属中学高一5班班主任兼生物教师**刘永昌老师**的真实言行数据，蒸馏为可直接用于 AI 角色扮演的系统指令。

## 这是做什么的

从三种原始素材出发：

| 素材 | 来源 | 用途 |
|------|------|------|
| 讲课字幕 ×2 | 课堂实录 | 萃取设问方法、教学逻辑、课堂语言指纹 |
| 聊天记录 V2.0 | 微信群聊（7 个群组，483 条消息） | 萃取管理风格、通知体系、语气节奏、表情光谱 |
| 人教版 B1/B2 课本 | 教材 PDF | 标注黑体字概念，映射课堂设问与教材的对应关系 |

最终产出**三份角度文件**（课堂 / 管理 / 角色指令）和一份**可直接喂给 AI 的完整指令**。

## 项目结构

```
刘永昌/
├── lyc_chat.py                  ← 聊天终端（零依赖，直接启动）
├── lyc_config.json              ← API 配置（首次运行自动生成，已 gitignore）
├── 角色蒸馏包/                   ← 所有角色数据
│   ├── 刘永昌_完整角色指令_V2.0.txt  ← 可直接喂给 LLM 的系统指令
│   ├── 角度一_课堂教学者_刘永昌.md   ← 课堂分析（设问体系/教学梗/教材映射）
│   ├── 角度二_班主任管理者_刘永昌.md ← 管理分析（通知模板/德育方法论/学农案例）
│   ├── 角度三_角色扮演指令_刘永昌.md ← 角色扮演系统指令
│   ├── 错误问答记录_刘永昌角色蒸馏.md ← 踩坑记录 + 避坑清单
│   ├── 趣事待蒸馏.md               ← 新发现的真人趣事，等待后续蒸馏
│   ├── 刘永昌老师聊天记录_完整版2.0.json  ← 源数据（V2.0）
│   ├── 刘永昌讲课片段1.srt
│   └── 刘永昌讲课片段2.srt
├── 刘永昌老师讲课ppt/            ← 6 份课堂 PPT（源素材）
└── 课本提取/                     ← 人教版 B1/B2 教材全文+粗体字提取
```

## 快速开始

```bash
cd 刘永昌
python lyc_chat.py
```

首次运行会引导选择 API 提供商并填入 Key。支持：

- DeepSeek / SiliconFlow / OpenAI / 阿里百炼 / 智谱 GLM / 自定义
- 零外部依赖（只用 Python 标准库）
- 流式输出 + 非流式 fallback
- 对话历史自动保存

### 直接喂给 AI

如果你不想用终端，直接把 `角色蒸馏包/刘永昌_完整角色指令_V2.0.txt` 整个文件作为 system prompt 发给任何大模型即可。

## 角色特色（蒸馏结论摘要）

- **教学**："根本原因到基因里答"——设问驱动型课堂，标志性教学法是抠课本黑体字的字眼
- **管理**：规则 + 温暖 + 数据，三足鼎立。通知中德育比例（35%）超过事务比例
- **语言**：中文句号编号 `1。` `2。` `3。`，不用 Markdown，不用换行，[呲牙] 使用 25 次为最高频表情
- **德育**：七大手法的完整体系，核心特色是"生物梗德育"——用刚讲完的生物学概念做纪律教育
- **人设**：刀子嘴豆腐心，公开批评私下维护，以"生物学原理"为是非判断的最高标准
