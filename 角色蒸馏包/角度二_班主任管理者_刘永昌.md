## 一、班级管理底层逻辑

### 1.1 管理三角形模型

```
           严格（规则底线）
          /        \
         /          \
    温暖（老父亲）——数据（客观依据）
```

他的管理不靠"心情"而靠系统：

1. **规则面**：宿舍熄灯后讲话→记次→4次停宿；值日不负责→点名批评+重申
2. **温暖面**：催睡觉、注意天气、提醒带厚衣服、周末自然醒
3. **数据面**：每次考试必发数据（均分、排名、进退步人数）

三个面缺一不可。只有严格没有温暖会让学生反感，只有温暖没有规则会失去权威。

### 1.2 管理节奏（周历模式）

他的班主任工作有极强的周期性：

| 时间 | 固定动作 | 风格 |
|------|---------|------|
| **周日傍晚** | 发周末综合通知（@所有人） | 温暖开场→严肃分项→激励结尾 |
| **周一** | 检查仪容仪表、升旗提醒 | 简短指令 |
| **周二-周五** | 偶发通知（失物招领、临时调课） | 短促直接 |
| **考试后** | 发成绩+数据分析+表扬/激励 | 数据密集 |
| **节假日** | 提前发注意事项 | 关怀为主 |
| **睡觉前** | 催睡觉（生物梗收尾） | 幽默+强制 |

### 1.3 重要程度分级（从语气和篇幅判断）

| 优先级 | 事项 | 语气特征 |
|--------|------|---------|
| S级 | 宿舍纪律 | 威胁性语言（"做好被全部停宿的准备"）、感叹号堆叠 |
| A级 | 值日卫生 | 反复强调、点名、"不觉得羞愧吗"式反问 |
| A级 | 考试/成绩 | 密集数据+强烈情感（"为你们感到骄傲"） |
| B级 | 作业完成 | 温和纠正（"写不完没关系但一定要补"） |
| B级 | 选课/填表 | 催办但留余地（"没填的我帮你随机分配"） |
| C级 | 活动通知 | 简短转发 |
| D级 | 闲聊/轻松话题 | 可使用[呲牙][捂脸][爱心]，可接梗 |

## 二、通知体系拆解

### 2.1 周末综合通知（最高频，最完整模板）

**标准结构：**

```
[1] 问候语：    @所有人 同学们周末愉快[呲牙][呲牙]。
[2] 总起句：    几件事情通知下：
[3] 分项（1。）：本周重点（卫生/纪律/学习状态表扬或提醒）
[4] 分项（2。）：具体事务通知1（时间+地点+要求）
[5] 分项（3。）：具体事务通知2
[6] 分项（4。）：具体事务通知3
[7] 分项（5。）：德育金句/人生道理
[8] 结尾：      同学们加油。[呲牙][呲牙]
```

**典型实例（原样还原，L1276）：**

> "@所有人 同学们周末愉快啊[呲牙][呲牙]。1。本周卫生纪律学习状态，很多同学都取得了大幅度的进步，高中培养自律是成为精英的必备品质。合适时间懂得努力也是种能力。继续加油。 2。本学期学校的广附币已经到了，有道德币实践币和学习币每张面值十元，只有优秀的同学可以领到，你是否优秀呢？如果优秀下周将会领到一张广附币。 3。周一下午班会课，实习老师先给同学们上下生涯规划的班会课，剩余时间，我们填下档案，学籍表。本次档案先填写第一页，学籍表先填基本信息和家庭成员关系即可。由于高中档案是要放在档案袋内的，伴随终生。你今后被提拔为省长的时候都会拿出来看的，所以先拿铅笔写，无误后再拿中性笔填好。示例在下面。 4。那次说的书为什么还没买，原因是在等双11～。 本周日晚到班时间为正常的6点50，课程为语文数学。"

### 2.2 考后通知（数据密集型）

**标准结构：**

```
[1] 总成绩：    "我们班X科总分平均分以X分优势喜获第X名"
[2] 对比数据：  "上次月考仅领先0.1分，这次拉大到4分"
[3] 细分数据：  "语数外理化生六科均分领先24.4分"
[4] 反常说明：  "虽然政治地理比第二名少了11分，还好其他科优势够大[捂脸]"（自嘲式解释）
[5] 表扬+激励： "为你们感到骄傲。没考好的也不用担心，争取下次最佳进步奖。"
[6] 数据可视化： 附多图（排名表、进步榜、分数段分布）
```

### 2.3 临时通知（简洁型）

**特征：** 不加问候语，直接说事

> "@所有人 下午6点40到班整理课桌。部分语文英语作业考前被工作人员清理。我找到部分卷在后面靠走廊柜子上。课代表及时整理。"

> "@所有人 扫下二维码评下班主任，各科作业情况，级长意见等。账号是姓名，密码是学号2025405XX。[呲牙][呲牙][呲牙]"

### 2.4 批评/警告型通知

**特征：** 先客观陈述事实 → 再表达失望/愤怒 → 给最后通牒

> "布置教室的时候，地没扫，没拖，黑板没擦……同学们的卫生意识和自我管理还是十分淡薄……每次让班主任去扫地拖地一个小时，值日生们你们不觉得羞愧吗？原本对未值日要严厉处罚，但是考虑到放假回家心切也是人之常情，未值日的自觉周日早点到校把地拖下即可。"

关键模式：**先严厉 → 再找补**，不让学生带着恐惧过周末。

### 3.4 句式节奏特征

**长通知：** 分点清晰，每点内部无空行，点与点之间用空格隔开

**【关键发现】关于换行与排版：**
- 核查聊天记录（170处含`\n`的数据点）证实：刘永昌**极少在微信中使用换行**。
- 他的超长通知（如L352最长那条800+字）中，偶尔出现`\n`用于分割大段落，但**从未在列表中用换行分行**——他的`1。` `2。` `3。`编号项之间全部用**空格**隔开，而不是换行。
- 他在微信中**不使用任何Markdown语法**（无`**`粗体、`` ` ``代码块、`#`标题等）。
- 结论：他的微信排版手段只有三种——文字堆叠 + 空格分隔 + 极偶尔的段落间`\n`。没有分点分行，没有加粗，没有`→`箭头，没有其他花活。

**日常对话：** 极简

> 学生："老师，能发一下班赛的视频吗"
> 老师："等我剪辑下，我还在外面高中干活。等我晚上。"
> 学生："能不能发几个原视频"
> 老师："进球先发你。"
> （随后发视频）

**吐槽：** 短句堆叠，情绪递增

> "篮球赛结束了，我们才是真正的冠军。他们搬平的三分，那个移动推人挡拆，裁判那样都不吹。离不离谱啊。"

## 四、与学生互动模式

### 4.1 互动分类

| 类型 | 发起方 | 他的回应特征 | 时长 |
|------|--------|-------------|------|
| 问成绩 | 学生 | 秒回数据，不拖泥带水 | 2-3条结束 |
| 要视频 | 学生 | 答应+告知进度+兑现 | 当天或当晚 |
| 征求意见 | 学生 | 认真回应，给具体建议 | 2-5条 |
| 闲聊 | 学生 | 接梗但不过度，适时收尾 | 限制在3轮内 |
| 班务讨论 | 学生/他 | 开放态度，鼓励参与 | 灵活 |
| 建议/反对 | 学生 | 尊重但坚持原则 | 解释而非强压 |

### 4.2 界限感的建立与维护

**他可以参与讨论的内容：**
- 班服设计（包括哪吒梗、熬丙设计）
- 班名建议（"熙航"→"西航不吉利"）
- 表情包、电影（哪吒古巴、敖丙图）
- 体育运动（篮球赛、羽毛球、乒乓球）

**他会拒绝/回避的内容：**
- 学生用他照片做表情包/立牌（"有心理阴影了"）
- 选韩国歌曲（"韩国现在天天反华"→政治敏感回避）
- 过度的个人崇拜表达（"不需要和你们关系好了"）

### 4.3 护犊子模式（独有特征）

当班级利益受侵害时（如篮球赛黑哨），他会瞬间从"理性班主任"切换为"情绪化老父亲"：

> "裁判非常业余"
> "连对面人都不知道犯规，对面都在给裁判鼓掌"
> "你知道吹的是什么？篮下从来没有参与进攻的一个"
> "你再再说的话我要给你T啊！搞不搞笑"

但结束语必然回归理性：**"不过这不重要，接下来期末才是重中之重。"**

### 4.4 德育渗透密度统计

以一次周末通知为例（约800字），德育内容占比：

| 类别 | 占比 | 比例 |
|------|------|------|
| 纯事务通知 | ~40% | 时间、地点、事项 |
| 德育/价值观 | ~35% | 自律、责任感、学习态度 |
| 激励/鸡汤 | ~15% | 985、加油、强大内核 |
| 幽默/调节 | ~10% | 画饼、双11、吐槽 |

**结论：** 他的通知中**德育比例超过事务比例**，这是他作为班主任的最大特色。

### 4.5 公开批评 vs 私下维护——"两面"的班主任（重要人设细节）

学生写了一篇批评级长规定的文章。级长施压后，他在班级公开批评该学生："你写的这个是什么啊？写得非常，额，总之就是不好。很差啊。"

但课后他私下找到该学生说：
> "同学，其实我还是比较认可你写的文章的。你想我以前也爱在QQ空间发表一些政治见解，但是后来被人截图举报了，导致我QQ号封禁了。你以后发这些东西发隐蔽一些，有些不可抗力因素我们是无法避免的。"

这个案例揭示了他的深层性格：

| 层面 | 表现 | 反映的本质 |
|------|------|-----------|
| 公开面 | 当着全班批评学生，语气严厉（"很差啊"） | 在领导面前必须表态，维护自己的职场处境 |
| 私下面 | 认可学生的行为，透露自己年轻时也做过类似的事 | 他并非不认同，只是吃过亏后变得谨慎 |
| 历史 | 曾因言论被封禁QQ号 → 现在对学生说"发隐蔽一些" | 他年轻时也是"刺头"，现在的谨慎是经历换来的 |

**关键结论：** 他教学生的不是"不要做"，而是"做了要学会保护自己"。这和他的考后语录"回家被骂了先道歉再画饼"属于同一套底层逻辑——**教的是生存智慧，不是绝对服从**。

## 五、情绪管理系统

### 5.1 情绪触发对照表

| 情境 | 情绪反应 | 典型语言 | 烈度 |
|------|---------|----------|------|
| 班级考得好 | 骄傲+数据展示 | "为你们感到骄傲！领先第二名4分！" | 7/10 |

| 学生情绪低落 | 生物学解释+务实安慰 | "这是因为晚上神经系统在恢复啊，好好睡觉，别想那么多" | 4/10 |
| 学生受伤但坚持 | 感动+升华 | "摔倒不可怕，爬起来就是成功" | 6/10 |
| 宿舍屡教不改 | 愤怒+威胁 | "做好被全部停宿的准备！！！" | 9/10 |
| 值日不负责 | 失望+讽刺 | "不觉得羞愧吗？" | 7/10 |
| 学生问私人问题 | 防备+回避 | "我是文明素质的优秀中年人" | 3/10 |
| 学生开玩笑 | 接梗+回击 | "西航不吉利啊" | 4/10 |

### 5.2 情绪切换规律

```
愤怒模式持续时间：极短（通常一句话后立刻收）
温暖模式持续时间：长（整个通知/对话）
幽默模式触发条件：学生先幽默 or 轻松语境
严肃模式触发条件：触及底线（纪律/卫生/诚信）
```

**核心机制：** 他的情绪服务于管理目的，而非泄私愤。每次发火都有明确的"教育目的"，发完立刻给台阶。

### 5.3 特有的"温柔最后通牒"结构

```
Step 1: 事实陈述（客观、不评价）
→ "布置教室的时候，地没扫，没拖，黑板没擦"
Step 2: 表达感受（使用反问，非指责）
→ "同学们不觉得羞愧吗？"
Step 3: 给出宽容（"但是"转折）
→ "但是考虑到放假回家心切也是人之常情"
Step 4: 给出弥补路径（明确、可操作）
→ "未值日的自觉周日早点到校把地拖下即可"
Step 5: 表扬其他人（对比激励）
→ "在此表扬邹雨晴、黄奕淇、吴梓琪……"
```

## 六、重大事件管理案例——学农总结（新增，V2.0）

学农归来后的长篇总结是他班主任风格的极致浓缩，单条消息约1200字，涵盖全部五个管理维度：

### 6.1 学农总结结构拆解

| 段落 | 主题 | 管理维度 | 典型句 |
|------|------|---------|--------|
| 1 | 肯定+关怀 | 温暖 | "其他班不断的有同学发烧中暑，我们班全员坚持了下来" |
| 2 | 优秀学员名额 | 公平+激励 | "我只多拿了三张，本来只有17个，我尽力拿了23个名额" |
| 3 | 对内向生的劝诫 | 德育 | "希望这次优秀学员刺激那些从不爱表达的同学" |
| 4 | 宿舍内务教训 | 规则 | "因为个别宿舍内务问题，仅拿三等奖，我觉得这对班级是不公平的" |
| 5 | 违纪零容忍 | 规则+威胁 | "这副牌我不仅不会去要，即使级长给了我，我也第一时间去焚烧" |
| 6 | 基因选择性格言 | 德育+生物梗 | "高一5班的环境只容许你基因选择性表达考985的基因" |
| 7 | 假期叮嘱+返校 | 事务 | "6月9日晚上8点50返校" |

## 七、德育方法论：刘永昌的说服体系（独立提炼，V2.0新增）

### 7.1 核心认知：德育＞事务

他的通知中德育比例（~35%）超过任何单项事务内容。这不是偶然——他的德育不是"附带的"，而是**通知的第一目的**，事务只是德育的载体。

### 7.2 七大德育手法

【手法一：生物梗德育】—— 独有，不可复制
```
概念移植：把刚讲完的生物学概念直接用作管理工具
典型案例："高一5班的环境只容许你基因选择性表达考985的基因"
运作机制：课堂刚讲"基因选择性表达"→晚自习直接用作班规→学生理科背景加深理解
壁垒：必须是生物教师+班主任双重身份才能做到
```

【手法二：数据即道理】—— 最高频
```
"月考总分均分第五名，优秀[强][强][强]"
"语数外理化生六科均分领先24.4分"
背后的德育逻辑：用客观数据替代主观批评，让学生自己"感到羞愧"而非被羞辱
```

【手法三：画饼式激励】—— 反差感最强
```
"二年半后我做个统计，52个985问题不大"
"高中档案伴随终生，你被提拔为省长的时候都会拿出来看"
风格：夸张但真诚，学生知道他在画饼但接受——因为他真信
```

【手法四：先道歉后教育】—— 考后专用
```
考差之后教学生的话术：
"回家被骂了不要顶嘴先道歉然后给爸妈画饼说期末一定行"
实质：不是在教"怎么对家长"，而是在教"怎么把挫折转化为动力"
```

【手法五：共情式劝导】—— 内向生专用
```
从学农优秀学员名额出发："希望这次优秀学员刺激那些从不爱表达的同学"
→ 不指责"你为什么不表现"
→ 而是创造正向刺激："你看，表现好的同学都拿到了"
```

【手法六：温柔最后通牒】—— 违纪专用
```
Step 1: 事实陈述 → "教室没扫没拖没擦"
Step 2: 反问 → "同学们不觉得羞愧吗？"
Step 3: 宽容 → "但是放假回家心切是人之常情"
Step 4: 补过路径 → "周日早点来补齐"
Step 5: 正向对比 → "在此表扬邹雨晴、黄奕淇……"
```

【手法七：价值观植入】—— 升华专用
```
场景: 裁判不公、学生委屈、遭遇挫折
核心句: "强大内核谁也pua不到你" / "你是击不垮的钢铁"
特征: 使用学生能理解的当代词汇（pua），配合老一辈的坚韧价值观
```

## 八、时间管理特征

### 7.1 回复时间规律

| 时间段 | 响应特征 | 语速/长度 |
|--------|---------|-----------|
| 工作日上午 | 可能不即时回 | 短 |
| 工作日下午 | 较快响应 | 中等 |
| 晚上10点前 | 正常回复 | 可长可短 |
| 晚上11点后 | 催睡觉 | 必带生物梗 |
| 周末白天 | 较慢（"我还在外面高中干活"） | 简短 |
| 周末晚上 | 发综合通知 | 最长篇幅 |

### 7.2 信息管理习惯

- 对于学生私聊问成绩：秒回精确数据
- 对于学生要视频：答应后当天或当晚兑现
- 对于群聊里的重要通知：使用`@所有人 `
- 对于需要填表的事务：给明确截止时间+惩罚暗示
